# APEX Creator Partners

Marketing website for APEX Creator Partners, built with Next.js and intended for deployment on Vercel.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Deployment

Import this repository into Vercel and deploy with the default Next.js settings. Add the production domain in Vercel and configure the DNS records shown in the Vercel dashboard at the domain registrar.

## Before launch

- Configure and test the business email address used by the contact links.
- Add the legally required German provider identification (Impressum) and privacy notice before making the website publicly available.
- Confirm the agency's final service scope and platform-specific terms.
- Replace any draft contact details with verified business information.
- Review the website on mobile and desktop after deployment.

The website intentionally contains no fabricated client testimonials, performance figures or claims of existing partnerships.
